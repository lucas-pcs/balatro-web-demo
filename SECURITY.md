# Security Policy

## Reporting a vulnerability

This project is a **static, client-side web app** — there is no backend, no
accounts, and no user data is collected or stored.

If you discover a security issue, please report it **privately**:

- Go to the repository's **Security** tab → **Report a vulnerability**
  (GitHub private security advisories).

Please **do not** open a public issue for security reports. We aim to
acknowledge a report within 7 days.

## Scope

**In scope**
- The web application source in this repository.
- The GitHub Actions build/deploy workflow (`.github/workflows/`).

**Out of scope**
- Third-party Balatro game assets bundled for reference (report to the game's
  owner, not here).
- Upstream npm dependencies (report to their respective maintainers).

## Supported versions

Only the latest version deployed from the `main` branch is supported.
